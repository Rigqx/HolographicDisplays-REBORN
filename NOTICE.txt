## About this fork

HolographicDisplays-Reborn is a modified version of the original Holographic Displays plugin, focused on keeping it working with newer Minecraft versions while maintaining support for older ones.

This release adds a new compatibility adapter for modern Minecraft versions, improves version detection (including Paper), updates item NBT handling, and includes a few build and documentation improvements.

All original APIs, legacy version adapters, and copyright notices have been kept. The internal plugin name is still `HolographicDisplays` to avoid breaking compatibility with existing plugins.
